Interactive Basics

How Web Pages Work

A webpage is a combination of structure, style, and behavior. Learn what each part does, then edit the code and watch the page update instantly.

Three building blocks

<h1> <button>

HTML gives your page structure. It defines what elements are on the page, such as headings, paragraphs, buttons, and images.

  • Think of it as the skeleton of a webpage.
  • It tells the browser, “This is a heading,” “This is a paragraph,” and so on.
  • Every web page starts with HTML content.
color: blue; padding: 20px;

CSS makes the page look good. It controls color, spacing, layout, fonts, and animations.

  • Think of it as the clothing and decoration of the page.
  • CSS selects elements and changes how they appear.
  • It makes your page readable and visually organized.
click addEventListener

JavaScript adds interactivity. It responds to clicks, updates content, and controls behavior.

  • Think of it as the brain or behavior of the page.
  • It can show alerts, change text, or animate elements.
  • JavaScript makes pages feel alive.
