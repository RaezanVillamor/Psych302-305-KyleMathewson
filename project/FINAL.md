# Final project · due Wednesday 2 December 2026

**Weight:** 35% of the course. Individual. Self as participant by default.

The page is the submission. There is no graded presentation and no peer review.

## Deliverables in your repository

1. A running page (HTML) **or** a Markdown methods-and-results file with an embedded or linked figure.
2. A written prediction dated before new data (the midterm check-in counts).
3. A result: one figure or table and a sentence that states the claim.
4. A limitation, including what your *n* can and cannot support.
5. Data file in `data/` if you collected any.
6. AI-use disclosure.

## Allowed tools

Use something already taught: simple or choice RT, the inventory, a two-condition comparison, or a short report site built from your existing files. No new libraries.

## Not required

Classmate data, a pair, a slide deck, or a statistical test beyond descriptives and a comparison you can explain.

## Graded

A clear measure, a written prediction, a visible result, and a stated limit.

## Not graded

Framework fashion, extra features for their own sake, or how long you speak in class.
